  While researching Intrusion Detection Systems for IoT networks, I framed the problem as One-Class Novelty Detection (OCND) to detect zero-day threats using exclusively benign traffic.
  The core challenge was balancing three conflicting constraints: detecting diverse anomaly structures (which requires tight decision boundaries) while tolerating training data contamination (which requires loose boundaries), all under extreme IoT resource constraints that preclude deep learning..
The core conflict is that detecting diverse anomalies requires tight decision boundaries, which makes the model highly fragile to contamination. Conversely, deep learning solutions that solve both violate IoT resource constraints.
  To resolve this trade-off, I proposed LOC-NFST (Local One-Class Null Foley-Sammon Transformation). Instead of using heavy deep learning models, I innovated on linear projectionsan innovative linear projection framework. I used K-means to capture the data's multi-modal structure via "pseudo-classes." To overcome the classical NFST algorithm's failure in one-class/high-sample settings, I introduced a spectral relaxation technique via SVD, projecting data into a "near-null" space. Finally, scoring samples by distance to pseudo-class centroids neutralized contamination noise while preserving the geometry needed to catch diverse anomalies.
  LOC-NFST achieved up to 99.39% AUC-ROC across 4 IoT datasets and tolerated 5% data contamination. By using efficient SVD matrix operations, it maintained a lightweight O(nd^2) linear time complexity, making it ideal for edge deployment.
